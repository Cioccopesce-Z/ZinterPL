for convenience variables, arrays and matrices are referred to as "data"

========================================================
BASIC RULES
========================================================

every instruction must end with :

example:

a = 5:
print_ a:
return_:

spaces are ignored except inside strings

example:

a = 5:

is equivalent to:

a         =         5:

but:

"hello world"

keeps spaces

execution starts from:

__start(){

}

functions may be declared before or after __start

========================================================
DATA TYPES
========================================================

all declared data can later be referenced simply by its name.

example:

int_ &i&counter&:

later:

counter = 5:
print_ counter:

the interpreter normally deduces the type automatically.

types:

i = integer
l = float
c = char variable
s = char array / string
f = file

immediate types:

n = immediate integer
k = immediate char

examples:

&i&number&
&l&temperature&
&c&letter&
&f&file&

&i[10]&numbers&
&l[10]&floats&
&s[50]&text&

&i[5][5]&matrix&
&l[5][5]&float_matrix&
&s[5][5]&char_matrix&

========================================================
DECLARATIONS
========================================================

int_ &i&var&:
int_ &i[size]&arr&:
int_ &i[rows][cols]&mat&:

float_ &l&var&:
float_ &l[size]&arr&:
float_ &l[rows][cols]&mat&:

char_ &c&var&:
char_ &s[size]&arr&:
char_ &s[rows][cols]&mat&:

========================================================
DATA ACCESS
========================================================

variable:

var

array:

[index]arr

matrix:

[row][col]mat

indexes may be constants:

[0]arr

[0][0]mat

or integer variables:

[idx]arr

[row][col]mat

indexes are always interpreted as integers.

========================================================
ASSIGNMENT
========================================================

variable:

a = 10:
a = b:
a = __func():

array:

[0]arr = 10:
[idx]arr = value:
[0]arr = __func():

matrix:

[0][0]mat = 10:
[row][col]mat = value:
[0][0]mat = __func():

examples:

a = b:

[0]arr = a:

[0][0]mat = [0]arr:

[0]arr = [0][0]mat:

========================================================
MATH OPERATORS
========================================================

supported:

+
-
*
/

examples:

c = a + b:
c = a - b:
c = a * b:
c = a / b:

operands may be:

numbers
variables
array elements
matrix elements
function returns

examples:

result = a + b:

result = [0]arr + [1]arr:

result = __func() + 5:

========================================================
INCREMENT / DECREMENT
========================================================

variables:

var++:
var--:

var++5:
var--5:

arrays:

[0]arr++:
[0]arr--:

[0]arr++5:
[0]arr--5:

for arrays:

[index]arr++

copies the content of the selected cell into the next cell.

example:

[0]arr = 50:

[0]arr++:

result:

[1]arr = 50

char arrays behave the same way:

[0]text = 'F':

[0]text++:

result:

[1]text = 'F'

========================================================
FUNCTIONS
========================================================

declaration:

od_ name(){

}

with arguments:

od_ sum(&i&a&!&i&b&){

}

arguments are separated by !

========================================================
FUNCTION CALLS
========================================================

void call:

__hello():

call with return:

result = __sum():

call with arguments:

__sum(10!20):

result = __sum(a!b):

functions may be used:

inside assignments
inside arrays
inside matrices
inside print_
inside return_

examples:

a = __sum():

[0]arr = __sum():

[0][0]mat = __sum():

print_ __sum():

return_ __sum():

========================================================
RETURN
========================================================

empty return:

return_:

return value:

return_ value:

return function:

return_ __func():

========================================================
COMPARISON OPERATORS
========================================================

==   equal

^=   different

>    greater

<    lower

>>   greater or equal

<<   lower or equal

all comparisons return:

1 = true
0 = false

examples:

a == b

a ^= b

a >> b

a << b

}

        esempio: int_ var: == in t_ va r: ma "in t_" var: è diverso da in t_ var:

==========funzioni matematiche=========== 
al posto delle variabili, dove logico, si possono mettere anche arr o num (non si puo salvare in un numero o immediate char)

[idx]name + var2:              viene aggiunto a var1/array in pos idx var2
var1 = var2 + var3:          la somma di var2 e var3 va in var1 

var1 = __somma():

un altro modo per assegnare:

set_to_variable/array/matrix_ name,type,index(only for array and matrix),index2(only for matrix),value,cvalue:
                                   ^
                                   |
                                imposta un valore(accetta come value o cvalue anche variabili matrici e array) ad ogni tipo 
                                di dato variabili/matrici/array, possono essere usate variabili come indici perr array e matrici
                                se si usa un dato int si deve mettere un place_holder in cvalue
                                ogni dato usato come indice viene forzato a integer 

============funzioni logiche=============
tutto quello contenuto negli if/for/while o in generale ! > < == sono funzioni che ritornano 0 o 1
e i cicli semplicemente eseguono ogni vola la funzione

if_( name !<>= name){      } <--- si possono concatenare con nd (and) o || (or) 
else_ {     }
for_( name !<>= name, name + - * / name){   } 
while_( name !<>= name){  }

=========dichiarazioni==========
vanno chiuse con :

int_ &i&name&

char_ &c&name&
char_ &s[dim]&name&

==========input output===========
vanno chiuse con :

scan_ &c&name&

scan_ &i&name&

print_ &c&name&

print_ &i&name&

scan_ name

scan_ name

print_ name

print_ name
print_ [idx]&name

println_ (stessa cosa ma va a capo dopo avere scritto)
