& i/n/k/l/c/f/s[idx]/i[idx]/l[idx]/s[idx][idx]/i[idx][idx]/l[idx][idx] &  nome  &
                    ^
                    |
            questa è una struttura dati in Z 
            quello contenuto tra i primi due &
            indica il tipo di dato:
            
    i = integer
    n = numero intero
    l = float 
    c = char solo per variabiili
    k = carattere diretto
    s = array di char o string solo per array
    f = file <--- NOT IMPLEMENTED
    s[idx] = indica un array di char e idx la posizione o la dimensione quando viene dichiarato
    i[idx] = indica un array di integer e idx la posizione o dimensione
        ^
        |
        idx puo essere se variabile: i/s[&i&var_name&], se reg: i/s[rN] o se numero int: i/s[N] 


--> &i&nome_variabile&  indica una variabile integer 

--> &s[15]&nome_variabile&  indica un array di string di 15 celle

la sintassi esplicita detta (&i&var&) non é necessaria (&i&var& = var)se non per le dichiarazioni int_ var non va bene
